# Navimaps iOS public distribution

Trang công khai: `https://navimapsios.github.io/`

Repository này chỉ dùng để phát hành Navimaps iOS. Website tự đọc release public của `navimapsios/navimapsios.github.io` và chỉ chấp nhận tag `ios-vX.Y.Z` có asset tên chính xác `Navimaps.ipa`.

Mã nguồn ứng dụng iOS không nằm trong repository public này. IPA được build từ workflow của repository nguồn và mirror sang đây bằng `PUBLIC_RELEASE_TOKEN`.
